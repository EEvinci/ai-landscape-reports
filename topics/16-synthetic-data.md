# Synthetic Data（合成数据）：LLM 训练的新基石

**研究时间：2026年4月 | 覆盖周期：2024–2025年**

---

## 一、背景：为什么合成数据在 2024–2025 年变得至关重要

高质量人类标注数据的枯竭，已成为大语言模型（LLM）继续 scaling 的核心瓶颈。传统 Scaling Law 依赖"更多参数 + 更多真实数据"的路径面临收益递减，而 2024 年以来的研究表明，**合成数据（Synthetic Data）**正在从辅助手段升级为 LLM 能力突破的关键引擎。

其核心逻辑是：利用现有强大 LLM（如 GPT-4、Claude、Gemini）的知识与推理能力，自动生成大规模、多样化、高质量的训练数据，从而绕开人工标注的成本与规模限制。这一转变催生了从数学推理、代码生成到常识推理的多项突破。

---

## 二、核心技术路径

### 2.1 LLM 生成数据（LLM-based Generation）

最基础的合成数据方法，是利用指令微调（Instruction Tuning）阶段由强模型生成训练样本。典型代表包括：

- **Self-Instruct**（Wang et al., 2022）：以少量种子指令引导 LLM 自生成_instruction_数据，显著降低人工标注成本
- **WizardLM / Evol-Instruct**：通过渐进式指令演化，生成复杂度递增的训练数据
- **Orca**（Microsoft）：从强模型的复杂解释轨迹（Explanation Traces）中学习，实现渐进式能力迁移

这些方法的核心局限在于：生成质量高度依赖种子数据质量，且缺乏对生成样本真实性的严格验证机制。

### 2.2 自我博弈（Self-Play）

自我博弈是让模型在不同能力水平上与自身对弈，以生成越来越强的训练信号。其在 LLM 语境下的代表作是 **AlphaProof**（DeepMind，Nature 2025）——将 AlphaZero 的自我博弈框架迁移到形式化数学证明领域：

- **数据生成**：用 Gemini 微调模型将 ~100 万道自然语言数学题自动形式化为 Lean 定理证明语言，经 MCTS 搜索扩展至约 1 亿道正式数学问题
- **训练**：每步 tactic 由 Lean 形式化验证器提供二元奖励信号（成功/失败），完全消除错误信号的干扰
- **测试时强化（TTRL）**：对难题生成数十万道变体进行针对性强化学习，曾在 IMO 2024 解答最难题（全场仅 5 名人类选手解出）

### 2.3 数据增强（Data Augmentation）

通过扰动现有数据生成变体，扩大训练分布的多样性。典型技术包括：

- **Source2Synth**（Meta，2024）：以真实网络表格/Wikipedia 为锚点，通过中间推理链生成问答对，在 HotPotQA 上提升 +22.57%，WikiSQL 上提升 +25.51%
- **提示词工程增强**：Few-shot 提示下生成多样化问题变体
- **多智能体协同**（Multi-Agent）：多个 LLM Agent 分工协作生成与验证数据，显著提升多样性与质量，但计算成本更高

## 三、标志性应用场景

### 3.1 数学推理：AlphaProof

DeepMind 的 AlphaProof 是合成数据驱动 LLM 能力跃升的标杆案例。2025 年发表于 *Nature* 的论文显示，该系统：

- 在 IMO 2024（国际数学奥林匹克）竞赛中取得 **28/42 分**（银牌水平，距金牌仅差 1 分）
- AlphaProof 独立解答 3 道非几何问题（代数 P1、数论 P2、最难题 P6），AlphaGeometry 2 补充解答几何题 P4
- 核心技术：基于 Lean 形式化验证 + AlphaZero 自我博弈，生成无限高质量数学证明训练数据

关键洞察：传统 LLM 依赖自然语言数学题库，数据量极为有限；AlphaProof 通过**自动形式化（Auto-Formalization）**将自然语言数学题大规模转化为可验证的形式化证明，破解了数学推理的数据稀缺难题。

### 3.2 代码生成：REFS / Self-Taught 系列

**STaR（Self-Taught Reasoner，NeurIPS 2022）**开创了自我博弈式推理 bootstrapping 范式：

1. 少量含推理链的种子数据 + 大量无标注数据
2. LLM 自生成推理过程（rationale）
3. 过滤正确样本用于微调
4. 对错误样本反向注入正确答案，引导生成正确推理链（rationalization）
5. 迭代循环，逐步提升模型推理能力

该方法被普遍认为是 OpenAI o1 推理模型的雏形。在代码生成领域，其思想延伸为**让模型自行生成正确代码样本并过滤验证**的训练范式。

### 3.3 常识推理

合成数据在常识推理中的核心价值在于**构建覆盖罕见、长尾场景的训练集**。通过 LLM 基于常见知识图谱自动扩展关系路径、生成反事实样本，显著改善模型在低频常识场景的表现。Source2Synth 等方法在多跳问答（Multi-hop QA）上的显著提升印证了这一点。

## 四、合成数据质量评估体系

合成数据的质量评估尚未形成统一标准，当前主流方法分为三个维度：

### 4.1 分布匹配（Distribution Matching）

验证合成数据与真实数据的分布一致性。EMNLP 2025 论文 "*Demystifying Synthetic Data in LLM Pre-training*"（1000+ 模型、10万+ GPU 小时的大规模系统研究）提供了关键结论：

- **改写型合成数据**（paraphrased natural text）：在可预期规模内**不造成性能下降**，且以 ~30% 混合比例可实现 **5-10 倍训练加速**
- **纯生成型合成数据**（textbook-style pure generation）：在下游任务上出现**更高的损失和性能退化**，尤其是小数据预算场景

### 4.2 多样性检验

衡量合成数据对原始分布的覆盖广度。核心指标包括：n-gram 多样性、主题覆盖度、指令类型多样性等。多智能体协同方法通过分工验证，显著提升了生成数据的多样性上限。

### 4.3 下游任务评估（Downstream Task Evaluation）

最直接有效的质量评估方式：

- 在标准 benchmark（Hendrycks Math、MATH、HumanEval 等）上评估微调后模型
- 留出 hold-out 验证集防止过拟合
- AlphaProof 的 gold standard：Lean 形式化验证器的二进制正确性信号提供了理论上无偏的质量判定

## 五、合成数据 vs 真实数据的核心权衡

### 5.1 分布偏移（Distribution Shift）

这是合成数据面临的最根本风险。EMNLP 2025 研究明确指出：

> **纯生成型合成数据**在下游任务上表现出系统性分布偏移——模型可能过拟合合成数据的特定模式，而在真实分布上泛化失败

最优解被证明是**混合策略**（约 30% 合成 + 70% 真实），而非完全替代。

### 5.2 模式崩溃（Mode Collapse）

模式崩溃指模型在反复用合成数据训练后，逐渐失去对真实数据分布尾部的建模能力。该研究为"模型崩溃"理论提供了**混合证据**：

| 合成数据类型 | 模式崩溃风险 | 证据强度 |
|------------|------------|---------|
| 改写型（paraphrased）| 低 | 强 |
| 纯生成型（pure-generated）| 高 | 强 |

这意味着：**数据来源的可追溯性（真实文本 vs 模型虚构）**是决定模式崩溃风险的关键变量。

### 5.3 真实数据不可替代的场景

某些能力（如文化特定表达、边缘长尾知识、实时信息）本质上无法通过合成数据习得。强模型的能力上限，仍受限于真实数据的多样性。

## 七、风险与挑战

### 7.1 模式崩溃与性能退化

如第五节所述，纯生成型合成数据的重复迭代训练会引发模型退化。根源在于：每次迭代的误差会在生成-训练循环中叠加放大，导致模型对原始真实分布的覆盖逐渐收窄。

### 7.2 重复与多样性丧失

当合成数据占比过高时，模型容易陷入**重复生成陷阱**——输出趋于模板化、缺乏创意。这一问题在纯生成型数据上尤为突出，改写型数据则相对稳健。

### 7.3 隐私与安全风险

尽管合成数据不直接复制原始训练数据，但研究表明：

- **成员推断攻击（Membership Inference Attack）**：模型在合成数据上过度训练，仍可能泄露训练集信息
- **对抗性合成**：恶意构造的合成数据可能包含隐蔽偏见或错误知识，经训练后被模型固化
- **隐私法规合规**：某些司法管辖区对"人工生成但来源于真实数据的合成数据"有特殊监管要求

## 八、总结与展望

合成数据已从"数据不足的权宜之计"演变为 LLM 能力建设的**核心基础设施**。2024–2025 年的关键进展揭示了以下规律：

1. **合成数据是杠杆而非替代品**：最优实践是将合成数据与真实数据按适当比例混合，而非完全替换
2. **验证机制决定质量上限**：AlphaProof 的成功证明，形式化验证器提供二元奖励信号可从根本上消除错误积累
3. **自我博弈是数学/代码等结构化领域的最佳范式**：在有明确正确性判断的领域，RL + 合成数据的效果远超监督微调
4. **混合智能体架构是未来方向**：多 Agent 分工验证显著提升数据质量，是 2025 年合成数据生成的前沿趋势

随着 LLM 能力的持续提升，合成数据的质量上限将同步提高——这意味着合成数据在 LLM 训练中的重要性，只会随时间加速增长，而不会触及天花板。
